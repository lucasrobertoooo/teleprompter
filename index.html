Configuração inicial

Feita uma única vez. Os roteiros ficam guardados criptografados no próprio repositório do GitHub, e qualquer aparelho acessa só com a senha.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Nome: teleprompter. Validade: a maior possível.
  3. Repository access: Only select repositories → escolha este repositório.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Gere o token e cole abaixo.
